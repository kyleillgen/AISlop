# Fonts

Bundled so the games load with no network and work offline. Both are variable fonts, Latin subset, as served by Google Fonts:

- `oswald-latin.woff2`: Oswald (weights 400–700) by Vernon Adams, Kalapi Gajjar and Cyreal.
- `inter-latin.woff2`: Inter (weights 400–600) by Rasmus Andersson.

Both are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and redistribution with software. `pinball-skin.js` loads them with `@font-face`, resolved relative to its own location.
